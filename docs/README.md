# Documentation

Rules and reference material used by people and agents alike.

| File | Contents |
| --- | --- |
| `note-templates.md` | The four note templates (regulatory, technical, organisation, person): required frontmatter, sections and their order. `validate_notes` checks every note against them |
| `extraction-guidelines.md` | Rules for extracting entities and relations from a note into `public/graph/extractions/`. The extraction agent's prompt includes them verbatim; the gold standard in `eval/gold/` follows them too |
| `extraction-examples.yaml` | Hand-labelled worked examples (few-shot) for the extraction prompt, from notes outside the gold standard |
| `weekly-run.md` | The weekly monitoring run as a graph (Mermaid), generated by `python -m app.agents.monitoring.weekly --diagram` |
