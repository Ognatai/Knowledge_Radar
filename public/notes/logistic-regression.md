## EN

> **Note:** LLM-generated summary based on the listed sources; it may be incomplete, outdated or wrong.

### TL;DR

Logistic regression is a linear model for classification: it computes a weighted sum of the input features and passes it through the logistic (sigmoid) function to obtain the probability of the positive class (Jurafsky & Martin, 2026; James et al., 2023). Weights are learned by maximum likelihood, which amounts to minimising the [[cross-entropy|cross-entropy]] loss, usually with [[gradient-descent|gradient descent]] or a dedicated solver; with more than two classes the sigmoid is replaced by the [[softmax|softmax]] (multinomial logistic regression) (Jurafsky & Martin, 2026). It is a standard baseline for text [[classification|classification]] and an analysis tool whose coefficients have a direct interpretation as changes in log odds (James et al., 2023).

### How it works

```text
features x = [x₁ … xₙ]
   ▼
z = w · x + b                 (logit = log odds, any real number)
   ▼
ŷ = σ(z) = 1 / (1 + e^(−z))   (probability of class 1)
   ▼
decision: class 1 if ŷ > 0.5
training: maximise Σ log p(y | x)  ⇔  minimise cross-entropy, plus regularisation
```

#### 1. Features and weighted sum

Each input is represented as a feature vector, for example counts of positive and negative lexicon words in a review; each feature gets a real-valued weight, positive weights count as evidence for the class and negative weights against it, and a bias (intercept) is added: `z = w · x + b` (Jurafsky & Martin, 2026). Features can be designed by hand, generated by templates such as all bigrams, weighted with [[tf-idf|tf-idf]] or learned as [[embeddings|embeddings]] (Jurafsky & Martin, 2026). Features with very different ranges are usually standardised to zero mean and unit variance (Jurafsky & Martin, 2026).

#### 2. Sigmoid and log odds

The sigmoid `σ(z) = 1 / (1 + e^(−z))` maps z to (0, 1), is nearly linear around 0 and squashes outliers towards 0 or 1 (Jurafsky & Martin, 2026). Linear regression on a 0/1 target can predict probabilities below 0 or above 1, which the logistic function avoids (James et al., 2023). Rearranged, `log(p / (1 − p)) = β₀ + β₁X`: the model is linear in the log odds (logit), so increasing a feature by one unit changes the log odds by its coefficient and multiplies the odds by `e^β` (James et al., 2023). In Jurafsky and Martin's sentiment example, weights `[2.5, −5.0, −1.2, 0.5, 2.0, 0.7]` and bias 0.1 give `P(+|x) = σ(0.833) = 0.70` for a short review (Jurafsky & Martin, 2026).

#### 3. Learning by maximum likelihood

Training chooses the weights that maximise the log probability of the correct labels given the inputs (conditional maximum likelihood); flipping the sign gives the cross-entropy loss `L = −[y log ŷ + (1 − y) log(1 − ŷ)]` (Jurafsky & Martin, 2026). James et al. (2023) prefer maximum likelihood to non-linear least squares for logistic regression because of its better statistical properties. The loss is convex, so gradient descent reaches the global minimum, and the gradient for one weight is `(ŷ − y) · x_j` (Jurafsky & Martin, 2026). [[scikit-learn|scikit-learn]] uses the `lbfgs` solver by default and recommends `newton-cholesky` when there are far more samples than features and `saga` for large data sets; `SGDClassifier(loss="log_loss")` fits the same model with stochastic gradient descent (scikit-learn).

#### 4. Regularisation

Without a penalty, a feature that happens to occur in only one class gets a huge weight and the model overfits; adding an L2 penalty (ridge) favours many small weights, an L1 penalty ([[ridge-and-lasso|lasso]]) favours sparse weight vectors with many zeros, and the bias is normally not penalised (Jurafsky & Martin, 2026; [[regularisation-and-hyperparameters|regularisation]]). In scikit-learn, regularisation is applied by default, which is common in machine learning but not in statistics; the parameter C is the inverse of the regularisation strength, smaller values mean stronger regularisation, and no regularisation corresponds to a very large C (scikit-learn; scikit-learn API reference).

#### 5. More than two classes

Multinomial logistic regression (softmax regression, in older NLP literature the maxent classifier) gives each of the K classes its own weight vector and bias and computes `ŷ = softmax(Wx + b)`; each row of W can be read as a prototype of its class (Jurafsky & Martin, 2026). The loss is the negative log probability of the correct class (Jurafsky & Martin, 2026). scikit-learn also offers one-vs-rest and elastic-net penalties (scikit-learn).

#### Origin and variants

Logistic regression is a generalised linear model with a Bernoulli or binomial distribution and a logit link (scikit-learn; James et al., 2023). It is also known as logit regression, maximum-entropy classification and the log-linear classifier (scikit-learn). In the layer counting of Jurafsky and Martin, logistic regression is a one-layer network, and a [[neural-networks|feed-forward network]] with a hidden layer is like multinomial logistic regression on features that the network learns itself instead of hand-designed templates (Jurafsky & Martin, 2026).

### When to use it

- Baseline for text classification such as sentiment, spam or language identification (Jurafsky & Martin, 2026).
- Binary decisions where calibrated probabilities matter, such as credit default (James et al., 2023; [[creditworthiness-assessment|creditworthiness assessment]]).
- Testing whether a feature is associated with an outcome while controlling for confounds (Jurafsky & Martin, 2026).
- Probing classifiers on top of frozen representations, as in Sentence-BERT's SentEval evaluation ([[sentence-bert|Sentence-BERT]]).

### Strengths and limitations

**Strengths**
- Interpretable: weight size and sign, and statistical tests such as the Wald or likelihood ratio test, show each feature's role (Jurafsky & Martin, 2026).
- Outputs probabilities, useful for downstream decisions and for combining systems (Jurafsky & Martin, 2026).
- Convex training, fast and well supported (Jurafsky & Martin, 2026; scikit-learn).

**Limitations**
- Linear decision boundary in feature space; interactions and non-linear effects must be built into the features (Jurafsky & Martin, 2026).
- Coefficients can change sign once other variables are included: in the Default data, students have higher default rates overall, but a lower default probability than non-students at the same balance and income (James et al., 2023).
- Unregularised weights overfit features that occur in one class only (Jurafsky & Martin, 2026).
- Inherits biases of its training data and features; most of 200 sentiment systems tested gave sentences with African American first names lower sentiment (Jurafsky & Martin, 2026; [[bias-in-nlp|bias in NLP]]).

### In practice

In the Default data, a logistic regression on card balance gives a default probability of 0.576% at a balance of 1,000 dollars and 58.6% at 2,000 dollars, which shows that the effect on the probability depends on where on the curve one is, even though the effect on the log odds is constant (James et al., 2023). Jurafsky and Martin (2026) recommend documenting classifiers with a model card covering training data, intended use and performance across groups. Probabilities can be checked and adjusted with calibration methods ([[platt-scaling|Platt scaling]], [[isotonic-regression|isotonic regression]]), and performance is reported with precision, recall and F1 ([[classification-metrics|classification metrics]]).

### Key takeaway

Logistic regression models the log odds of a class as a linear function of the features, is trained by minimising cross-entropy, and remains the interpretable baseline for classification.

## DE

### TL;DR

Die logistische Regression ist ein lineares Modell für die Klassifikation: Sie bildet eine gewichtete Summe der Eingabemerkmale und gibt sie durch die logistische Funktion (Sigmoid), um die Wahrscheinlichkeit der positiven Klasse zu erhalten (Jurafsky & Martin, 2026; James et al., 2023). Die Gewichte werden per Maximum Likelihood gelernt, was der Minimierung des [[cross-entropy|Cross-Entropy]]-Verlusts entspricht, meist mit [[gradient-descent|Gradientenabstieg]] oder einem eigenen Solver; bei mehr als zwei Klassen ersetzt die [[softmax|Softmax]] die Sigmoidfunktion (multinomiale logistische Regression) (Jurafsky & Martin, 2026). Sie ist eine Standard-Baseline für die Text-[[classification|Klassifikation]] und ein Analysewerkzeug, dessen Koeffizienten sich direkt als Änderungen der Log-Odds deuten lassen (James et al., 2023).

### Funktionsweise

```text
Merkmale x = [x₁ … xₙ]
   ▼
z = w · x + b                 (Logit = Log-Odds, beliebige reelle Zahl)
   ▼
ŷ = σ(z) = 1 / (1 + e^(−z))   (Wahrscheinlichkeit von Klasse 1)
   ▼
Entscheidung: Klasse 1, wenn ŷ > 0,5
Training: Σ log p(y | x) maximieren  ⇔  Cross-Entropy minimieren, plus Regularisierung
```

#### 1. Merkmale und gewichtete Summe

Jede Eingabe wird als Merkmalsvektor dargestellt, etwa als Häufigkeiten positiver und negativer Lexikonwörter in einer Rezension; jedes Merkmal erhält ein reellwertiges Gewicht, positive Gewichte zählen als Beleg für die Klasse, negative dagegen, und ein Bias (Achsenabschnitt) wird addiert: `z = w · x + b` (Jurafsky & Martin, 2026). Merkmale lassen sich von Hand entwerfen, über Templates wie alle Bigramme erzeugen, mit [[tf-idf|TF-IDF]] gewichten oder als [[embeddings|Embeddings]] lernen (Jurafsky & Martin, 2026). Merkmale mit sehr unterschiedlichen Wertebereichen werden meist auf Mittelwert null und Varianz eins standardisiert (Jurafsky & Martin, 2026).

#### 2. Sigmoid und Log-Odds

Die Sigmoidfunktion `σ(z) = 1 / (1 + e^(−z))` bildet z auf (0, 1) ab, ist um 0 nahezu linear und drückt Ausreißer Richtung 0 oder 1 (Jurafsky & Martin, 2026). Eine lineare Regression auf ein 0/1-Ziel kann Wahrscheinlichkeiten unter 0 oder über 1 vorhersagen, was die logistische Funktion vermeidet (James et al., 2023). Umgeformt gilt `log(p / (1 − p)) = β₀ + β₁X`: Das Modell ist linear in den Log-Odds (Logit), sodass eine Erhöhung eines Merkmals um eine Einheit die Log-Odds um seinen Koeffizienten verändert und die Odds mit `e^β` multipliziert (James et al., 2023). Im Sentiment-Beispiel von Jurafsky und Martin ergeben die Gewichte `[2,5, −5,0, −1,2, 0,5, 2,0, 0,7]` und der Bias 0,1 für eine kurze Rezension `P(+|x) = σ(0,833) = 0,70` (Jurafsky & Martin, 2026).

#### 3. Lernen per Maximum Likelihood

Das Training wählt die Gewichte, die die logarithmierte Wahrscheinlichkeit der richtigen Labels gegeben die Eingaben maximieren (bedingte Maximum Likelihood); mit umgekehrtem Vorzeichen ergibt sich der Cross-Entropy-Verlust `L = −[y log ŷ + (1 − y) log(1 − ŷ)]` (Jurafsky & Martin, 2026). James et al. (2023) ziehen für die logistische Regression Maximum Likelihood der nichtlinearen Methode der kleinsten Quadrate vor, weil sie bessere statistische Eigenschaften hat. Der Verlust ist konvex, sodass der Gradientenabstieg das globale Minimum erreicht, und der Gradient für ein Gewicht ist `(ŷ − y) · x_j` (Jurafsky & Martin, 2026). [[scikit-learn|scikit-learn]] nutzt standardmäßig den Solver `lbfgs` und empfiehlt `newton-cholesky`, wenn es weit mehr Beispiele als Merkmale gibt, und `saga` für große Datensätze; `SGDClassifier(loss="log_loss")` passt dasselbe Modell mit stochastischem Gradientenabstieg an (scikit-learn).

#### 4. Regularisierung

Ohne Strafterm erhält ein Merkmal, das zufällig nur in einer Klasse vorkommt, ein riesiges Gewicht, und das Modell passt sich zu stark an; ein L2-Strafterm (Ridge) bevorzugt viele kleine Gewichte, ein L1-Strafterm ([[ridge-and-lasso|Lasso]]) dünn besetzte Gewichtsvektoren mit vielen Nullen, und der Bias wird normalerweise nicht bestraft (Jurafsky & Martin, 2026; [[regularisation-and-hyperparameters|Regularisierung]]). In scikit-learn ist Regularisierung voreingestellt, was im maschinellen Lernen üblich ist, in der Statistik aber nicht; der Parameter C ist der Kehrwert der Regularisierungsstärke, kleinere Werte bedeuten stärkere Regularisierung, und keine Regularisierung entspricht einem sehr großen C (scikit-learn; scikit-learn-API-Referenz).

#### 5. Mehr als zwei Klassen

Die multinomiale logistische Regression (Softmax-Regression, in älterer NLP-Literatur der MaxEnt-Klassifikator) gibt jeder der K Klassen einen eigenen Gewichtsvektor und Bias und berechnet `ŷ = softmax(Wx + b)`; jede Zeile von W lässt sich als Prototyp ihrer Klasse lesen (Jurafsky & Martin, 2026). Der Verlust ist die negative logarithmierte Wahrscheinlichkeit der richtigen Klasse (Jurafsky & Martin, 2026). scikit-learn bietet außerdem One-vs-Rest und Elastic-Net-Strafterme an (scikit-learn).

#### Ursprung und Varianten

Die logistische Regression ist ein verallgemeinertes lineares Modell mit Bernoulli- bzw. Binomialverteilung und Logit-Link (scikit-learn; James et al., 2023). Sie ist auch als Logit-Regression, Maximum-Entropy-Klassifikation und log-linearer Klassifikator bekannt (scikit-learn). In der Schichtzählung von Jurafsky und Martin ist die logistische Regression ein einschichtiges Netz, und ein [[neural-networks|Feedforward-Netz]] mit verborgener Schicht gleicht einer multinomialen logistischen Regression auf Merkmalen, die das Netz selbst lernt, statt auf handentworfenen Templates (Jurafsky & Martin, 2026).

### Wann einsetzen

- Baseline für Textklassifikation wie Sentiment, Spam oder Spracherkennung (Jurafsky & Martin, 2026).
- Binäre Entscheidungen, bei denen kalibrierte Wahrscheinlichkeiten zählen, etwa Kreditausfall (James et al., 2023; [[creditworthiness-assessment|Kreditwürdigkeitsprüfung]]).
- Prüfen, ob ein Merkmal mit einem Ergebnis zusammenhängt, unter Kontrolle von Störfaktoren (Jurafsky & Martin, 2026).
- Probing-Klassifikatoren auf eingefrorenen Repräsentationen, wie in der SentEval-Evaluation von Sentence-BERT ([[sentence-bert|Sentence-BERT]]).

### Stärken und Grenzen

**Stärken**
- Interpretierbar: Größe und Vorzeichen der Gewichte sowie statistische Tests wie der Wald- oder Likelihood-Ratio-Test zeigen die Rolle jedes Merkmals (Jurafsky & Martin, 2026).
- Gibt Wahrscheinlichkeiten aus, die für nachgelagerte Entscheidungen und das Kombinieren von Systemen nützlich sind (Jurafsky & Martin, 2026).
- Konvexes Training, schnell und gut unterstützt (Jurafsky & Martin, 2026; scikit-learn).

**Grenzen**
- Lineare Entscheidungsgrenze im Merkmalsraum; Wechselwirkungen und nichtlineare Effekte müssen in die Merkmale eingebaut werden (Jurafsky & Martin, 2026).
- Koeffizienten können das Vorzeichen wechseln, sobald andere Variablen hinzukommen: In den Default-Daten haben Studierende insgesamt höhere Ausfallraten, bei gleichem Saldo und Einkommen aber eine niedrigere Ausfallwahrscheinlichkeit als Nicht-Studierende (James et al., 2023).
- Unregularisierte Gewichte passen sich zu stark an Merkmale an, die nur in einer Klasse vorkommen (Jurafsky & Martin, 2026).
- Übernimmt Verzerrungen ihrer Trainingsdaten und Merkmale; die meisten von 200 getesteten Sentimentsystemen bewerteten Sätze mit afroamerikanischen Vornamen negativer (Jurafsky & Martin, 2026; [[bias-in-nlp|Bias in NLP]]).

### In der Praxis

In den Default-Daten ergibt eine logistische Regression auf den Kartensaldo eine Ausfallwahrscheinlichkeit von 0,576 % bei einem Saldo von 1.000 Dollar und 58,6 % bei 2.000 Dollar; das zeigt, dass die Wirkung auf die Wahrscheinlichkeit davon abhängt, wo auf der Kurve man sich befindet, obwohl die Wirkung auf die Log-Odds konstant ist (James et al., 2023). Jurafsky und Martin (2026) empfehlen, Klassifikatoren mit einer Model Card zu dokumentieren, die Trainingsdaten, vorgesehenen Einsatz und Leistung über Gruppen hinweg beschreibt. Wahrscheinlichkeiten lassen sich mit Kalibrierungsverfahren prüfen und anpassen ([[platt-scaling|Platt Scaling]], [[isotonic-regression|isotone Regression]]), und die Leistung wird mit Precision, Recall und F1 berichtet ([[classification-metrics|Klassifikationsmetriken]]).

### Merksatz

Die logistische Regression modelliert die Log-Odds einer Klasse als lineare Funktion der Merkmale, wird durch Minimieren der Cross-Entropy trainiert und bleibt die interpretierbare Baseline der Klassifikation.
