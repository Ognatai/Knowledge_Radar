# Application

- `backend/`: Python package `knowledge_radar`: note loading/validation, the
  static-site export, local configuration, and the FastAPI backend of the local app.
- `site/`: the public static site (React), deployed to GitHub Pages.
- `frontend/`: the local app UI (chat + Review Dashboard), planned.
- `agents/`: the agent pipeline.
- `mcp/`: MCP servers.

See [SETUP.md](../SETUP.md) for how to run everything.
